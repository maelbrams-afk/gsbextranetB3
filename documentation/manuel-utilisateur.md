# Manuel utilisateur

## Médecin

1. Se connecter avec son adresse e-mail et son mot de passe.
2. Ouvrir sa messagerie : un code à 6 chiffres est envoyé par mail. Le saisir sur la page « Vérification en deux étapes » dans la minute qui suit. Si le code a expiré ou n'est pas arrivé, cliquer sur **Renvoyer un code**.
3. Ouvrir **Produits** dans le menu.
4. Cliquer sur **Consulter** pour lire l'objectif, les informations et les effets indésirables d'un produit.

## Chef de produit

En plus de consulter les produits, le chef peut :

- **Ajouter un produit** puis compléter tous les champs et enregistrer.
- Ouvrir une fiche et choisir **Modifier** ou **Supprimer**.
- Ouvrir **Statistiques** pour voir les consultations et les produits les plus consultés.

Chaque création, modification et suppression est inscrite dans le journal.

## Administrateur

Le lien **Administration** donne accès à :

- l'activation ou l'arrêt du mode maintenance ;
- aux statistiques de consultation ;
- aux 100 dernières opérations sur les produits, avec le compte, l'adresse IP et la date.

Pendant la maintenance, les médecins et chefs voient un message d'indisponibilité. L'administrateur peut encore se connecter pour remettre le site en service.

## Déconnexion

Utiliser le lien **Déconnexion** dans le menu. Ne jamais communiquer son mot de passe ni son code de connexion à un autre utilisateur.
