# GSB Extranet

Projet PHP de l'extranet GSB. La partie administration des produits, les statistiques, la maintenance et les rôles sont décrits dans le [backlog](documentation/backlog.md).

Avant d'utiliser ces nouvelles fonctions, appliquer la migration de base de données décrite dans la [documentation technique](documentation/documentation-technique.md). Les livrables de la mission comprennent le [MCD](documentation/MCD.md), les [cas de tests](documentation/cas-tests.md) et le [manuel utilisateur](documentation/manuel-utilisateur.md).
